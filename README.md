# KrafovDev

**Версия 0.1.0**

Персональный сайт-портфолио Тимура Крафова — Full Stack разработчика. Одностраничный сайт с информацией обо мне, используемом стеке, проектах и контактами.

## Возможности

- Одностраничная вёрстка с якорной навигацией
- Разделы: «Обо мне», «Стек», «Проекты», «Контакты»
- Тёмная тема с акцентным зелёным цветом
- 3D-эффект наклона карточек проектов при наведении
- Отключение анимаций при `prefers-reduced-motion`

## Технологии

- HTML5
- CSS3 (переменные, Grid, Flexbox)
- JavaScript без зависимостей
